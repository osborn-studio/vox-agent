Vox Agent · Design Direction Review

原生 macOS 语音 Agent 工作台
—— 三个高保真方向

不是聊天软件，不是 web console。三个方向共用同一副三栏骨架（ChatWindow / ChatInputBar / Inspector），分别押注：可信、能力表达、输入方式的独占性。

方向 01 — 03 目标 macOS 14+ · SwiftUI 基线 vox-agents/macos

mockup 内为 SF 系统字体 · 忠实 HIG
01
Calm Native Cockpit
安静 · 专业 · 像 Apple 自己会做的 agent 工具

押注可信。界面在你不需要它时消失。零装饰色、零 toast、零 modal——层级全部由字重与灰度承担，语音是输入手段而非表演。

1

状态点是唯一的功能色

绿=运行 / 橙=待批准 / 红=错误 / 灰=空闲。侧栏用 .sidebar 材质透出桌面，badge 只出现在需要人介入的地方。

2

回合制，不是气泡

用户输入 = 2pt 竖线 + 波形图标 + 转写文本；agent 响应 = 无底色正文块。工具调用折叠成一行 mono disclosure。悬停才浮现操作按钮。

3

润色状态写进文字本身

输入栏里灰色 = raw ASR，黑色 = 已润色定稿。不用图标不用弹层，文字颜色就是管线状态。

4

Inspector 四段式

Task / Memory / Permissions / Log。Permissions 是信任卖点：agent 拿到什么权限、用了几次、何时过期，随时可查。

02
Agent Operations Desk
任务调度 · 队友协作 · 状态监控 —— mission control

押注能力表达。Agent 是队友不是聊天对象，对话只是任务的载体。scheduler、permissions、task history、WebSocket events 全部升为一等公民——结构上就不可能被误认为聊天软件。

1

全局 status strip

running / queued / awaiting / failed 四段常驻，点击即过滤中心时间线。整个方向的灵魂控件，MenuBarExtra 显示同一组数字。

2

Roster 左缘色条

2pt 色条比圆点扫视更快：蓝=运行 / 橙=待批准 / 红=错误。第二层是当前任务 + 微型进度条。消息可直接拖到 agent 上转发。

3

权限 inline 审批

权限请求是时间线里的可操作卡：具体权限、作用域、过期时间、Approve/Deny 就地一击。这是 web console 给不了的 1 秒操作。

4

Operations 三区常驻

Now Running（WebSocket 直推）/ Queue & Schedule（可拖拽重排）/ History & Audit。不用 tab——作战台不藏信息。

03
Voice Command Center
语音是主输入设备 · 界面为说话让路

押注输入方式的独占性。像专业音频软件对待声音那样对待语音：三态精确可辨、润色倒计时可见、误识别两秒入典。全局 push-to-talk + 浮动 HUD 是 web 永远做不到的场景。

1

话筒对着谁，永远无歧义

当前语音目标带 amber 描边，数字键 1–9 直接切换。「聆听中 / 响应中 / 静默」是 agent 的语音关系状态。

2

语音消息带信任锚点

波形可回放原音频；raw 转写可展开对照；字典修正词带点状下划线。润色错了，随时回去听原话。

3

三态 voice stage（上方按钮可试）

Idle 完全安静 → Listening 真实振幅波形 + amber 呼吸描边 + 逐词转写 → 停顿 1.5s 倒计时环 → Processing 波形冻结、灰字定稿为黑字。

4

误识别 2 秒入典

Inspector 的 Voice 面板显示 provider 延迟、failover 状态、润色 diff。「四快跑 → scraper」一键写入 dictionaries——把 ASR 弱点变成信任特性。

帮我查一下今天 CI 有没有红…
esc 取消 · tab 切换目标 · app 未激活也可用
全局浮动 HUD（push-to-talk）。app 不在前台时长按热键唤出：波形 + 实时转写 + 目标 agent，松键即发送，HUD 淡出。戴着 AirPods 在房间里走动指挥 agent——这是原生 app 的独占场景，也是 30 秒 demo 视频的开场镜头。采音状态四重冗余提示（菜单栏、HUD、描边、系统橙点），绝不静默录音。

结论：三选一是假命题

以 01 Calm Native 为底盘（可信入场券），取 02 Operations 的右栏与状态语法为深度（回答"为什么不用 web console"），取 03 Voice 的输入栏与全局 push-to-talk 为招牌时刻（回答"为什么叫 Vox"）。
STEP 1 · 性价比最高

状态色语法统一

左栏色条 + 顶部 status strip + MenuBarExtra 聚合状态。改造量小，后端能力表达提升最大。

STEP 2 · 纯 UI 活

权限请求 inline 卡

permissions 后端已有。把审批从"去别处找"变成时间线里的 1 秒一击，顺带产出审计记录。

STEP 3 · 招牌时刻

Voice stage 三态 + 倒计时环

ChatInputBar 已有雏形。把 ASR → 停顿检测 → 润色 → 字典这条已有管线变成看得见的信任感。

02 的完整 operations 右栏与 03 的全局 HUD 放第二梯队——第一梯队上线后，用你自己的真实输入比例（语音 vs 打字）决定押哪边。
