# Vox Agent 4.2.1 — bundled Qwen3-ASR option

The offline asset is `VoxAgent-v4.2.1-qwen3-asr-0.6B-arm64.dmg`. It supplements the existing cloud DMG on the same preview release; it does not silently replace that asset or its checksum. It uses the same native application and Python engine as the 4.2.1 cloud package.

Contents:
- Official `Qwen/Qwen3-ASR-0.6B` snapshot `5eb144179a02acc5e5ba31e748d22b0cf3e303b0`, including tokenizer/config files and original weights.
- Weight SHA-256 `79d6cbd4c98c7bbffe9db2edac07f56cd6637d0d5944b27f6c2b8353840323ea` (1,876,091,704 bytes), verified against official Hugging Face LFS metadata.
- Self-contained Python/MLX sidecar in `Contents/MacOS`, with `mlx-qwen3-asr==0.4.4`, `mlx==0.29.3` and `mlx-metal==0.29.3` (macOS 14 wheels).
- Model files in `Contents/Resources/Models/Qwen3-ASR`, which the existing native loader checks before user caches.
- Apache-2.0 model license, source revision, dependency licenses and installed runtime version inventory.

The app's existing runtime quantizes the loaded model to four bits in memory; the distributed model weights remain the original official weights. No GGUF chat model, diarization model or forced aligner is included. ASR can run locally; optional cloud polishing and agent execution keep their independent requirements. This does not enable offline Feishu synchronization or finish pending Feishu-login acceptance.

Build using `scripts/build_qwen_offline_dmg.sh` with SOURCE_APP, QWEN_MODEL_DIR, QWEN_PYTHON and a new OUTPUT_DIR. The script validates the model hash, preserves the source app, packages a sidecar, copies licenses, signs the resulting app and generates a separate DMG/checksum. Use a volume with several GB free. Full model weights and build artifacts are release assets, never source-control files.

This is an Apple Silicon preview. macOS 14 is the runtime wheel target; only the current development Mac is tested, not every macOS release. Existing 4.2.1 migration and rollout limitations still apply.

## Acceptance on 2026-09-26

On the development Apple Silicon Mac (macOS 26.6.2), launched the actual packaged sidecar using an empty temporary HOME/HF_HOME, `HF_HUB_OFFLINE=1` and a macOS sandbox denying outbound network except localhost. Model warmup took 8.1 seconds. `/health` returned `model_loaded=true`, and `/transcribe` returned exactly “Hello, this is an offline speech recognition test.” for synthetic 16 kHz mono PCM. No user recordings were used. This verifies the bundled runtime/model without a pre-existing cache; it does not claim a full native microphone/UI or older-macOS test.

osstack syntax/whitespace verification passed (loop_924e672f-7339-4318-9a4f-de02b660227a). The model weights are unchanged and the cloud app's native executable is reused. The sidecar is frozen as one file to avoid PyInstaller's macOS app-layout relocation issue.

A second isolated, network-denied test using synthetic Mandarin speech returned exactly “你好，这是离线语音识别测试。”. The final DMG is 1,611,629,062 bytes; `hdiutil verify` passed. DMG SHA-256: `0df9e3f7edff211b042a60915e392dcbdf712f98086763ffb6f8e21e05c8ab30`.
