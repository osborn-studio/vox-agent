# Vox Agent 4.1.0

Vox Agent 4.1.0 is the owner relaunch candidate for the upgraded Agent product.
It keeps Mission Control as the primary macOS experience while restoring a
reproducible release baseline.

## What is included

- **Vox Agent product surface.** Mission Control, the Agent timeline, scoped
  approvals, voice capture, memory, and operations controls remain the
  user-facing product. `VoxLog` remains only in internal Swift module,
  executable, and migration-compatible persistence names.
- **P3.3 conversation foundation.** Face-to-face sessions and expiring,
  single-use remote QR participation use final transcript and cited final
  translation events.
- **Reproducible quality gate.** Ruff 0.15.22 is pinned in both local
  development dependencies and GitHub Actions.
- **Dependency hardening.** Root and mobile dependency locks contain no known
  high or critical npm advisories at qualification time.

## Explicitly not included

P3.3E live interim transcript drafts and phone-to-session streaming audio are
not part of this release. They remain dependencies of the internal iOS
TestFlight program and must not appear in product claims until their contract,
privacy, and physical-device gates pass.

External TestFlight, public internet ingress, paid entitlements, language
learning memory, Windows physical qualification, and commercial Mac
notarization remain separate release gates.

## Qualification

- Python 3.11/3.12 tests and pinned Ruff lint
- TypeScript API/contracts, Web, desktop, and mobile tests
- Root and mobile high-severity npm audit gates
- Rust formatting/tests and pinned RustSec audit
- Swift tests and release build with warnings treated as errors
- DMG bundle, signature, architecture, embedded-engine, update-manifest, and
  isolated-home smoke checks before publication
