# Vox Agent 3.3.0

Vox Agent 3.3.0 is the first release that presents the product as an agent
cockpit rather than a VoxLog-style transcript viewer. It keeps legacy Swift
target and data-path identifiers only for compatibility.

## What changed

- Replaced chat bubbles with an execution timeline for prompts, agent answers,
  tool activity, status, duration, and sources.
- Added scoped inline permission cards with approve/deny audit history and no
  blind approval from the menu bar.
- Added an operations inspector for running, queued, scheduled, and historical
  tasks, including pause, cancel, and rerun actions.
- Added a global voice HUD and a five-state voice input flow with live waveform,
  transcript, countdown, processing, and target-agent context.
- Added versioned reconnectable streaming speech events with partial/final
  revisions, language, speaker, monotonic time, idempotency, cancellation, and
  cursor replay.
- Added Enterprise foundations: users and roles, hashed bearer credentials,
  authenticated control-plane and WebSocket routes, tenant isolation,
  actor-bearing audit records, persisted retention policy, and scheduled
  deletion sweeps.
- Bundled the Python engine inside the macOS app so the release DMG does not
  depend on a source checkout or system Python installation.
- Unified user-visible naming and product positioning on **Vox Agent**.

## Install on macOS

The repository is private, so authenticate with a GitHub account that has
access, then download the release asset:

```bash
gh auth login
gh release download v3.3.0 \
  --repo gilosbornhello/vox-agents \
  --pattern 'VoxAgent-v3.3.0-cloud.dmg'
open VoxAgent-v3.3.0-cloud.dmg
```

Drag `Vox Agent.app` into Applications. The test build uses an ad-hoc signature;
if Gatekeeper blocks first launch, confirm this exact downloaded build in
System Settings > Privacy & Security and choose Open.

Requirements: Apple Silicon Mac, macOS 14 or later.
