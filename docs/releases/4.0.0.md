# Vox Agent 4.0.0

Vox Agent 4.0.0 changes the Mac product from a conversation-first voice logger
into a multi-Agent mission control surface.

## What is new

- **Mission Control is the default workspace.** Launch now opens on real Agent
  work rather than a transcript timeline.
- **Operational truth at a glance.** Running, queued, awaiting-approval, and
  failed counts come from the canonical Engine and shared status store.
- **Live work and human attention.** Active tasks, pending scoped approvals,
  and failures are separated into action-oriented sections.
- **Agent fleet navigation.** Select any real Agent to open its Command
  timeline; `Command-1` opens Mission Control and `Command-2` opens Command.
- **Inline permission review.** Mission Control links to the exact scoped
  approval card. It never approves an unseen action.
- **Cross-platform hardening.** The Windows shell includes its global voice HUD,
  and History no longer interpolates backend-controlled fields into WebView
  HTML.

The `VoxLog` name remains inside the Swift module and persistence paths only so
existing user data continues to work. The app, repository, release assets, and
user-visible experience are **Vox Agent**.

## Install on Apple silicon Mac

```bash
gh release download v4.0.0 \
  --repo gilosbornhello/vox-agents \
  --pattern 'VoxAgent-v4.0.0-cloud.dmg'
open VoxAgent-v4.0.0-cloud.dmg
```

Drag **Vox Agent.app** to Applications, then launch it. The release bundle
contains the arm64 SwiftUI app and a self-contained arm64 Agent Engine; no
source checkout or separate Python installation is required.
