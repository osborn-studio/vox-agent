# Vox Agent 3.3.1

Vox Agent 3.3.1 is the recommended MacBook Pro test release. It contains the
full Vox Agent cockpit upgrade from 3.3.0 plus two release-path hardening fixes.

## Fixed

- The native app now waits for the bundled engine's real `/health` response
  before reporting `running` or connecting its event WebSocket. A freshly
  downloaded PyInstaller engine may need several seconds for its first cold
  start; the old fixed 1.5-second assumption could expose a false-ready state.
- GitHub verification and DMG publishing now use the current Node 24 runtime
  generations of Checkout, Setup Python, Setup Node, Upload Artifact, and the
  release publisher action.
- App bundle, Python package, engine OpenAPI, update manifest, and DMG filename
  now agree on version 3.3.1, protected by a release-version contract test.

## Vox Agent upgrade included

- Agent execution timeline instead of VoxLog chat bubbles.
- Scoped inline permission cards and actor-bearing audit history.
- Operations inspector with pause, cancel, and rerun controls.
- Global voice HUD and five-state voice command input.
- Versioned, reconnectable streaming speech events.
- Users/Roles, authenticated control plane, tenant isolation, and persisted
  retention sweeps.
- Self-contained macOS engine; no source checkout or system Python required.

## Install on macOS

The repository is private, so authenticate with a GitHub account that has
access:

```bash
gh auth login
gh release download v3.3.1 \
  --repo gilosbornhello/vox-agents \
  --pattern 'VoxAgent-v3.3.1-cloud.dmg'
open VoxAgent-v3.3.1-cloud.dmg
```

Drag `Vox Agent.app` into Applications. On the first launch, allow the bundled
engine time to unpack and become ready. The test build uses an ad-hoc signature;
if Gatekeeper blocks it, confirm this exact download in System Settings >
Privacy & Security and choose Open.

Requirements: Apple Silicon Mac, macOS 14 or later.

## Qualification status

The macOS app, bundled engine, checksum manifest, and CI matrix are automated
release gates. Physical iOS, Android, and Windows qualification and the named
Enterprise private-team pilot still require external devices/operators and
remain explicitly `PENDING`.
