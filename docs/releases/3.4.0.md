# Vox Agent 3.4.0

Vox Agent 3.4.0 adds the cited realtime translation foundation to the upgraded
agent cockpit. It keeps the existing Vox Agent interface and execution controls
while extending the bundled engine, authenticated gateway, shared contracts,
and mobile client for multilingual workflows.

## Added

- A strict `POST /v1/translations` contract whose input contains authenticated
  final-segment references, explicit BCP 47 source and target languages,
  glossary terms, consent, remote-processing policy, and an idempotency key.
- Typed final and failure events with provider/model metadata, confidence,
  glossary hits, and citations back to the source speech segments.
- An OpenAI-compatible remote translation adapter with exact structured output,
  safe error normalization, prompt-injection boundaries, and local identity
  translation for same-language requests.
- A gateway proxy and typed mobile client. Offline or unavailable translation
  returns an explicit failure instead of fabricated text or timings.
- A reproducible 12-case benchmark across six Simplified Chinese, Japanese, and
  English directions. The qualified Qwen Plus run recorded 100% required-term
  recall, 100% glossary compliance, and 2,241 ms p95 latency.

## Security and reliability

- The engine resolves transcript contents server-side and rejects forged,
  partial, evicted, or language-mismatched references.
- Remote translation is opt-in and requires consent. macOS provider credentials
  remain in Keychain and are exposed only to the bundled child engine process.
- Idempotency is principal-scoped; concurrent duplicates collapse to one
  provider call, while transient failures remain retryable.
- Engine stderr is continuously drained, bounded, and redacted so a noisy child
  process cannot deadlock or leak bearer/API-key material into logs.
- Translation audit records carry actor/workspace and operational metadata but
  never transcript or translated contents.

## Install on macOS

The repository is private, so authenticate with a GitHub account that has
access:

```bash
gh auth login
gh release download v3.4.0 \
  --repo gilosbornhello/vox-agents \
  --pattern 'VoxAgent-v3.4.0-cloud.dmg'
open VoxAgent-v3.4.0-cloud.dmg
```

Drag `Vox Agent.app` into Applications. The ad-hoc test build requires Apple
Silicon and macOS 14 or later. If Gatekeeper blocks first launch, confirm the
exact download in System Settings > Privacy & Security and choose Open.
