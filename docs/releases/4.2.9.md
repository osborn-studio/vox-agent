## 2026-10-18 macOS composer candidate (ad-hoc signed DMG)

Source: `main` after PRs #1, #2 and #3 of `osborn-studio/vox-agent`. This is a
macOS-only candidate build of the 4.2.9 line for the owner's own Mac; the
version pins stay at 4.2.9 and this section is not a release announcement.

What changed since the installed 4.2.4:

- **Codex-style composer.** The chat input is two rows: a toolbar row with the
  Polish model badge (opens Models settings when no model is configured) and a
  text area that grows upward to eight lines before scrolling. Geometry lives in
  `ChatLayoutMetrics`; DESIGN.md records the two-row contract as an owner
  decision of 2026-10-18.
- **Translate in the composer.** The Translate button translates the draft in
  place (Chinese ⇄ English, direction detected from the text) using the same
  provider and model as Polish; Undo restores the original draft.
- **Polish failures are visible.** When Polish fails (network, timeout, provider
  error) the composer shows the reason inline and keeps the draft instead of
  sending the unpolished text silently.
- **Timeline translation removed.** The unreachable per-message translation
  plumbing in the Feishu timeline is gone; the composer Translate replaces it.
- **Feishu renewal diagnostics.** Session renewal logs one line per attempt
  (outcome, hashed user, device prefix, upstream code) and the account view shows
  session validity and the last renewal outcome as plain captions. Raw audio,
  transcripts and tokens never enter these logs.
- **CI restored.** `.github/workflows/verify.yml` runs Python lint and tests,
  Swift tests and the release build on GitHub-hosted runners for pull requests;
  `.github/workflows/release-dmg.yml` builds the DMG on demand (see below).

How to build the DMG: Actions › Release DMG › Run workflow on `main`, leave the
version empty (it must equal the Info.plist version, 4.2.9). The run uploads
`VoxAgent-v4.2.9-cloud.dmg` and `SHA256SUMS.txt` as the artifact
`vox-agent-v4.2.9-dmg`; the checksum is also printed in the job summary.

Signing: the DMG is **ad-hoc signed**. This repository holds no Developer ID
certificate or notarization credential, so Gatekeeper blocks the first launch of
the installed app. Right-click (or Control-click) `Vox Agent.app` in
Applications and choose **Open** once; later launches open normally. The
installed app replaces the 4.2.4 bundle in place and keeps its Keychain items and
local data.

Verified for this candidate: Python lint and tests, `swift build -c release`
and `scripts/build_voxagent_dmg.sh` on the development Mac (MacOSX26.5 SDK,
ad-hoc signature verified, `hdiutil verify` valid); Swift tests run in the Verify
workflow. Not verified: physical GUI acceptance on the owner's Mac, Developer ID
notarization, and the Windows package, which is why the 4.2.9 GAP table above is
unchanged.
