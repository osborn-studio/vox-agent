# Vox Agent 3.5.0

Vox Agent 3.5.0 turns the desktop Cockpit into a real Agent operations client.
It no longer treats a local VoxLog task cache or a memory lookup as proof that an
Agent task ran.

## What is upgraded

- The shipping macOS SwiftUI app reconciles specialist Agents, canonical task
  IDs and lifecycle state, and pending approvals from the Python Agent Engine.
- Typed commands use the engine orchestrator at `/v1/message`; the response and
  server `task_id` appear in the Agent timeline.
- WebSocket events trigger immediate reconciliation, while a five-second
  snapshot loop recovers state after disconnects or missed events.
- Pending approval cards are rebuilt after reconnect and decisions still use the
  authenticated HTTP control plane. The bundled personal edition uses its local
  administrator identity; Enterprise clients must provide an administrator
  bearer credential.
- The cross-platform Tauri Cockpit uses the same operations contract and keeps
  its engine credential inside the operating-system credential store.
- The obsolete Swift client-to-server WebSocket task request was removed. The
  WebSocket is now unambiguously a server event stream.
- The task database persists `source_agent`, preserving origin and audit context
  through a schema migration.

## Install on Apple Silicon Mac

The repository is private, so authenticate with a GitHub account that has
access:

```bash
gh auth login
gh release download v3.5.0 \
  --repo gilosbornhello/vox-agents \
  --pattern 'VoxAgent-v3.5.0-cloud.dmg'
open VoxAgent-v3.5.0-cloud.dmg
```

Drag `Vox Agent.app` into Applications. This test build is ad-hoc signed and
requires macOS 14 or later. If Gatekeeper blocks the first launch, approve the
exact downloaded app in System Settings > Privacy & Security.

## Qualification

Automated Python, Swift, TypeScript, mobile, Rust, dependency-audit, contract,
packaging, and GitHub CI gates must pass before the tag is published. The DMG is
also mounted and inspected to confirm it contains both the SwiftUI executable
and the self-contained Agent Engine.

Physical iOS/Android/Windows qualification, commercial notarization, and the
named Enterprise private-team pilot remain external release gates and are not
represented as complete by this macOS test release.
